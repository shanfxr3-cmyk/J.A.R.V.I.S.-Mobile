# Security

Found a security problem in J.A.R.V.I.S.? Please email shanakhter777@gmail.com
before posting it publicly. Include the app version (Settings, About) and what you did.
I'll reply as soon as I can, usually within a few days.

Official builds are only the APKs on this repository's Releases page, signed with the key
fingerprint listed in NOTICE. Don't install copies from anywhere else.

Maintainer note: the release signing key lives in GitHub Actions secrets, so keep two-factor authentication switched on for the GitHub account.
