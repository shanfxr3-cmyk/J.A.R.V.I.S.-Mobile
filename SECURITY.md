# Security

Found a security problem in J.A.R.V.I.S. Mobile? Please email shanakhter777@gmail.com
before posting it publicly. Include the app version (Settings, About) and what you did.
I'll reply as soon as I can, usually within a few days.

Official builds are only the APKs on this repository's Releases page, signed with the key
fingerprint listed in NOTICE. Don't install copies from anywhere else.

Maintainer note: the release signing key lives in GitHub Actions secrets, so keep two-factor authentication switched on for the GitHub account.

Hub (optional, run by you): it needs a long random token, listens on localhost only and is meant to be reached through a tunnel. Wrong tokens are rate-limited per client address while a correct token is never locked out. Web text the AI reads cannot make it change memory, watches or the TV in the same request. Keep `config.json` and `creds.json` out of git (the `hub/.gitignore` already does). See hub/HUB.md.
